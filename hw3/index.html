Assignment overview

Automate a travel landing page from a city or country entered in Google Sheets. Groq generates content; n8n builds responsive HTML with images and a map; Gmail handles approve/reject; approved runs update the sheet; every execution is backed up to GitHub.

Workflow flow

Google Sheets Trigger (Pending)
    → Get Row → Prepare Prompt → Groq JSON → Validate JSON
    → Build data → HTML → GitHub (travel-pages/ + backups/)
    → Gmail Send and Wait (Approve / Reject + Comment)
    → IF approved?
         YES → Update Sheets + confirmation email
         NO  → Version++ → Regenerate (comment / no comment) → loop (max 3)

Quick start

  1. Use the Google Sheet (see setup guide).
  2. Import workflow/travel-page-automation.json into n8n.
  3. Add credentials: Groq, Google Sheets, Gmail, GitHub.
  4. Set a row to Status = Pending and activate the workflow.
  5. Screenshot the generated HTML page for submission.
